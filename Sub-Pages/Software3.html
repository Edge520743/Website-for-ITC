Aleph: Software

What is Computer Hardware?

Computer hardware are the physical components of the computer system. If you drop anything and it clatters, then that's hardware.

Hardware is part of an umbrella of components which build the computer in the physical level:

  • Hardware - All encompassing components that are not software nor considered software
  • Architecture - The internal organization of the computer represented in an abstract form which defines the capabilities of itself.
  • Organization - The method of implementation of the computer in relation to all of its components.

What is Computer Software?

Software is defined as the set of instructions that perform specific tasks. It additionally is the whole computing facility, and suite of programs, procedures, routines, etc. that are provided to the user, excluding the hardware. Software is usually stored in non-volatile long-term storage.

Software in general needs to appease the human personalities of: Extroversion and Introversion, Sensing and Intuition, Thinking and Feeling, Judgement and Perception.

Software also follows a cycle called the “Software Development Cycle” and has a hierarchy known as the “Software Stack”, where the lowest ranking software are able to talk directly to the system’s hardware.

Types of System Software:

System Software is defined to be low-level software that sits in between the computer’s hardware and application software

  • Operating Software - Type of a collection of software which assists in program execution. The operating system is a “core” software in order for application software to even function.
  • Device Drivers - Type of software which interfaces with the hardware in order for it to function properly.
  • Firmware - Embedded software in the read-only portion of the system. Firmware in general allows low-level control of the system, something that the Operating System cannot allow you to do.
  • Utility - Software that configures, maintains, and supports the maintenance of the system.

Types of Application Software:

Application Software is defined to be high-level software which have specific functions for the end-user to use

  • Word Processors - Designed for documentation and typing data. Word Processors allow users to format their text in order for certain occasions and uses.
  • Database Software - Allows the user to create, manage, and organize their data
  • Multimedia Software - Allows the user to perform various actions that are related to the “media” umbrella such as images, music, video, etc.
  • Freeware - Software that is downloaded on the internet which is free-to-use for a lifetime.
  • Shareware / Trialware - Software that is downloaded on the internet but only has a “limited-time” use. After the trial period ends, you are then required to pay upfront in order to continue using.
  • Open Source - Software that is similar to freeware, with the added benefit of being able to modify their source code freely.
  • Programming Software - Type of software that allows the user to use text to write code using programming languages (C++, C#, Java, etc.).

How Does Hardware Communicate?

Hardware is the physical components of the computer, and can be collected, touched, and done whatever.

Hardware Communicates via the following:

  • Binary - On / Off signals used by the system, very similar to morse code (dots, dashes, and spaces).
  • Logic Gates - The basis for processing binary input to allow decision-making in hardware
  • Machine Code & Assembly - Classified as a software that speaks directly to the computer’s hardware components
  • Instruction Execution - The CPU’s process of fetching, decoding, and executing its given instructions.
  • Input / Output Systems - Classified as software that interprets the input from the computer’s hardware, and sends a reply back to the computer (feedback).
  • Logic Gates

The 7 Logic Gates:

  • AND - Returns 1 if both A and B are 1
  • OR - Returns 1 if either A or B are 1
  • NOT - Reverses the input of either A and B (i.e. 1 becomes 0)
  • NOR - Can take more than two inputs, and returns 1 if all inputs are 0.
  • NAND - Can take two or more inputs, and returns 0 if all inputs are 1.
  • XOR - Returns 1 if A and B do not equal each other.
  • XNOR - Returns 1 if A and B equal each other.

Hardware is also the circuits and logic gates inside the computer, which allows the computer to draw power, and properly run the software.

The Different Parts of a Computer

Hardware nowadays are very essential in conjunction with software since: It stores, contains, and is required by software components to function, enhances the speed of the application directly and effectively than software alternatives, is very resilient and is very reliable (especially when working under stress), can be future-proofed since as it is easily scalable, and can be customized and tailored by the user or manufacturer through firmware coding. Below are the main parts of computer hardware:

    Motherboard

  • The main hub that connects, and allows all other hardware components to talk to each other.

    • Central Processing Unit

  • The brain of the computer, it guides the computer in data processing.

    • Random Access Memory

  • Communicates closely with the CPU as it stores temporary information for the CPU to immediately use. RAM is classified as “volatile memory”, meaning that data is flushed as soon as power is lost

    • Power Supply Unit

  • Takes electricity from the mains and passes it to the computer’s motherboard in order to power the components

    • Graphics Processing Unit

  • Processes graphical data in order to display video.

    • Random Access Memory

  • Communicates closely with the CPU as it stores temporary information for the CPU to immediately use. RAM is classified as “volatile memory”, meaning that data is flushed as soon as power is lost

    Computer Drive

  • Non-volatile storage drive used for storing software and saving long-term data.

    • Hard Disk Drive

  • Stores binary data into magnetic platters. Usually lasts longer, and is cheaper than SSDs at the cost of slower speeds.

    • Solid State Drive

  • Stores data on NAND flash memory chips. Is faster than HDD at the cost of slightly shorter lifespan.

Uses of Hardware & Software

For Education:

  • Computers were implemented in various public schools in the Philippines, which were proven to be effective.
  • Additionally, tablets were also deployed in 9 public schools under the Australian AID tablet computer program, which resulted in the implication of success from the program in general.
  • Dynamic Local Area Network was also utilized in a college in order to prepare, deploy, and check the student’s mock board exams. This method proved effective since it was quite convenient for both the student and the personnel.

For Healthcare:

  • Software is relevant in healthcare since software traits such as usability, reliability, and efficiency proved to be effective for user satisfaction, quality of patient care, clinical workflow, efficiency, etc.
  • Computerized decision systems were also tested in order to see if they had benefits in terms of mortality rates. The results showed that while they did not reduce morality, they did provide moderate benefits for morbidity and clinical efficiency.

Reflection

Computers, a modern miracle of mankind, compounded by both hardware and software. Without computers, automation, computer related fields and science, technological marvel and innovation would cease to exist. I have realized that we as humans take computers for granted as under that towering system lies a complex, rigorous, and robust set of instructions that keep everything maintained. It is similar to a tower of bricks, where each brick comprises the entire structure. Remove a single brick, and the structure wanes, remove dozens of bricks and everything comes crashing down. In general, computers are made of two parts, hardware and software. The hardware are the things you can touch, such as the motherboard, the CPU, the drive, etc. whereas the software are the parts you cannot touch nor feel, but the parts that you will interact with the most through the human computer interaction principles. All hardware requires software to run properly, and every component is linked through the motherboard. Placing a component outside to the motherboard is similar to placing a brick outside of its structure. Sure, the brick is there, but it cannot be used by the structure, nor can it be moved to the structure by itself. It becomes unused, and useless. Therefore, the motherboard is in general the main structure of the computer, and the central hub that allows communication with different core components. Core components (such as the CPU, graphics card, etc.) must be placed in the motherboard in order to communicate, and allow functionality with each other.

With the increase in the amount of computer users in the world slowly and steadily increasing, institutions, government agencies, companies, and charity groups have taken interest in modernizing their campuses, workplace, or providing to countries in need. Computers are heavily favored by these large corporations since they are the main gateway to connecting to the internet. Even mobile devices are sufficient enough to allow users to have the full-feel of what a computer is like. Additionally, there is a benefit to utilizing both computers and software as everyone will be familiar with what they are, and how to navigate them, which results in more business, more favorable outcomes, and more engagement in general. Therefore, allowing computers to modernize your entire area is not a bad idea as it improves business in general so long as you weigh the importance, necessity, and cost required to set computer systems up. In conclusion, computers are made up of hardware and software, which can be simply broken down akin to a building made out of bricks, where each brick plays an important role in keeping the structure, design, and complex calculations of the system running. Due to the popularity of computers, most people are implementing them in their workplace, with huge amounts of success in general. So long as the computers work best in that environment, and businesses have enough money to fund these components, computers are a good future investment as one of their benefits is familiarity due to everyone having seen, known, and used a computer before.
